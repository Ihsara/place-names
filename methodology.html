What this maps

Every named settlement (OSM place=city/town/village/hamlet/suburb) in Finland, Sweden, and Vietnam, fetched via the workspace osmkit toolkit.

How a name is matched

Finland: the compound-final suffix of the single written word (longest curated suffix wins, casefolded). Vietnam: the first whitespace syllable, with tone marks and đ significant (Tân ≠ Tan, Đông ≠ Dong), Unicode-normalised.

Sweden: matched the same way as Finland — the compound-final suffix of the single written word, longest casefolded match wins, from a curated set of 10 Swedish morphemes (e.g. -sjö lake, -fors rapids, -vik bay, -berg hill, -näs cape, -by village).

Each place gets at most one morpheme. Unmatched places appear as faint dots so density and the gaps (e.g. Khmer/Cham/montagnard naming in the Vietnamese south and highlands) stay visible. The morpheme set is curated for the story, not exhaustive. Counts are as of the build date.

The Sweden ↔ Finland concept bridge

The bridge pairs morphemes that name the same landscape concept across the two languages — it does not introduce any new morphemes. Each side of every pair is one of the existing curated Finnish or Swedish morphemes already matched above. The six pairs:

  • lake — Swedish -sjö ↔ Finnish -järvi
  • rapids — Swedish -fors ↔ Finnish -koski
  • bay — Swedish -vik ↔ Finnish -lahti
  • hill — Swedish -berg ↔ Finnish -mäki
  • cape — Swedish -näs ↔ Finnish -niemi
  • village — Swedish -by ↔ Finnish -kylä

All six pairs are attested on both sides in the real data — there are 0 dead pairs (every morpheme in every pair occurs at least once in its country's settlements).

The unique-by-province lens

This lens asks a different question: which name-elements are confined to one province rather than spread across the country?

  • Provinces: admin_level=4 boundary polygons, fetched via osmkit/Overpass.
  • Spatial join: each settlement is assigned to a province by point-in-polygon.
  • Element key: for Finland and Sweden, the casefolded last four characters of the name (a suffix proxy); for Vietnam, the first whitespace token (NFC normalised).
  • Confinement rule: an element is "confined" when it occurs at least 3 times total and at least 70% of its occurrences fall in a single province.
  • Province score: the count of distinct confined elements anchored to that province.

The 0.7 threshold was chosen against the live data — high enough that an element is genuinely local, low enough that real regional substrates survive. On the real data the top provinces are Varsinais-Suomi (Finland, 17), Västra Götalands län (Sweden, 62), and Đắk Lắk (Vietnam, 36) — the last carrying Central-Highlands substrate elements ea and krông.

Substrate glosses

A few Vietnamese elements come from older, non-Vietnamese tongues that show through where one province names the world its own way. The unique-by-province drill panel lists each confined element with its count× and the % falling in that province — it does not print a gloss. Two glosses worth noting (not shown in the UI):

  • đăk — "water" (Bahnaric / Mon-Khmer); this element is confined in the live data, anchoring the Central-Highlands substrate.
  • bản — "village" (Tai / Thái); included as background only — it does not meet the confinement rule in the current build.

These glosses are curated; verify before citing. They are offered as a reading aid for the substrate story, not as authoritative etymology.

The terrain layer

The faint geography under the dots is OpenStreetMap water, coastline, and rivers (natural=water, natural=coastline, waterway=river), simplified for display (~0.015° ≈ 1.7 km) and thresholded to drop minor features — tiny ponds, sub-2 km coastline skerries, short river stubs — so only the geography that gives a name its reason remains. It is deliberately not a basemap: no roads, no labels, no tiles; only the physical ground a name sits on. Map framing uses stepped presets — Whole country, Region, Cluster — rather than free pan, so each view has a stable, named frame of reference. Terrain geometry © OpenStreetMap contributors.
